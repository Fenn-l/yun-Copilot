# IT 常见故障处理手册

本手册汇总办公电脑、打印机、软件与账号权限的常见问题。

## 一、电脑蓝屏或频繁重启

1. 记录蓝屏界面上的错误代码（如 IRQL_NOT_LESS_OR_EQUAL），并拍照留证。
2. 最近安装过新软件或驱动的，进入安全模式卸载最近的更新。
3. 检查硬盘剩余空间，系统盘建议保留 20GB 以上可用空间。
4. 运行系统自带的磁盘检查和内存诊断工具。
5. 如果 24 小时内重复出现两次以上，请提交「技术问题」工单，附上错误代码与发生时间，IT 会安排检测或更换设备。

## 二、打印机无法打印

1. 确认打印机电源开启，面板无报错，纸张与墨粉充足。
2. 在「设备和打印机」中查看默认打印机是否正确。
3. 取消卡住的打印任务队列后重新打印。
4. 重启 Print Spooler 服务：在服务管理器中找到 Print Spooler，右键重新启动。
5. 网络打印机需要确认与电脑在同一网段；无法访问时记录打印机 IP，提交工单由 IT 配置。
6. 共享打印机提示「驱动程序不可用」时，请从内网软件中心安装对应型号驱动。

## 三、软件安装与授权

- 办公软件、开发工具请优先从内网「软件中心」下载安装，避免来源不明的安装包。
- 需要商业授权或付费软件的，提交「软件申请」工单，注明软件名称、版本、使用场景与预算。
- 安装来源不明的破解软件属于违规行为，安全软件会拦截，且可能导致账号风险。
- 软件安装失败时，附上错误截图与安装包名称，便于 IT 判断是权限问题还是安装包问题。

## 四、账号与权限申请

1. 新员工入职默认开通邮箱、VPN、办公协作套件三项基础权限。
2. 访问业务系统、数据库、代码仓库等需要单独申请，由直属主管在权限平台审批。
3. 权限申请工单需注明系统名称、需要的角色、使用期限与业务理由。
4. 转岗或离职时，原权限会在 3 个工作日内回收；如需保留部分权限，请在转岗流程中说明。
5. 发现账号出现异常登录、权限异常增大时，立即修改密码并联系 IT 安全专员。

## 五、病毒与安全事件

- 收到可疑邮件或附件时不要打开，直接标记为垃圾邮件并举报。
- 安全软件报警时不要强行关闭，按照提示隔离文件。
- 如果电脑出现异常弹窗、文件被加密、账号异地登录，请立即断开网络并联系 IT 安全值班人员，不要自行重装系统。
- 安全事件处理期间请配合提供日志与操作记录，IT 会按安全流程进行取证。

## 六、数据丢失与备份

1. 重要文件请保存在部门共享盘或个人网盘，不要只放在本地桌面。
2. 误删除文件可先在回收站或网盘「最近删除」中恢复，保留期为 30 天。
3. 硬盘损坏导致无法开机时，不要反复通电尝试，提交工单由 IT 评估数据恢复。
4. 数据恢复不保证 100% 成功，请养成定期备份习惯。

## 七、硬件报修

电脑、显示器、键鼠等硬件故障请提交「技术问题」工单，注明资产编号与故障现象。IT 会在 1 个工作日内响应，需要更换硬件的，按资产管理制度走领用流程。
