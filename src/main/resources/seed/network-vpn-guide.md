# 办公网络与 VPN 使用指南

本指南适用于总部办公区、分支机构与远程办公场景。

## 一、办公区网络连接

1. 优先连接「Company-Office」无线网络，认证账号为工号，密码为统一身份认证密码。
2. 如果无法搜索到无线网络，请确认无线开关已打开，并尝试靠近 AP 或有线接入。
3. 有线网络采用 DHCP 自动获取地址；如提示「无法获取 IP 地址」，请拔插网线或重启网络适配器。
4. 访客网络「Company-Guest」仅可访问互联网，不能访问内部系统，访客账号由前台申请，有效期 1 天。

## 二、VPN 连接步骤

远程办公访问内部系统、代码仓库、数据库管理平台时，需要先连接公司 VPN。

1. 从内网首页下载并安装 VPN 客户端（Windows / macOS / Linux 版本）。
2. 服务器地址填写 vpn.company.com，端口 443。
3. 使用统一身份认证账号登录，首次登录需要完成短信二次验证。
4. 连接成功后，客户端状态显示「已连接」，此时可以访问 internal.company.com 等内网地址。

## 三、VPN 常见故障

### 错误 691：用户名或密码错误
- 确认使用的是统一身份认证密码，而不是邮箱密码。
- 账号连续失败 5 次会被锁定 30 分钟。
- 密码过期时，请先在自助服务门户修改密码。

### 错误 809：无法建立连接
- 检查本机网络是否正常，尝试访问外网网站。
- 关闭其他 VPN 或代理软件，避免端口冲突。
- 如果处于酒店或机场网络，可能需要更换网络或使用手机热点重试。

### 连接成功但无法访问内网
1. 断开后重新连接 VPN。
2. 刷新 DNS 缓存：Windows 打开命令行执行 ipconfig /flushdns。
3. 确认访问的是内网域名而不是公网 IP。
4. 检查系统代理设置，取消「全局代理」后重试。

### VPN 频繁断开
- 检查网络信号是否稳定，优先使用有线网络或稳定的 Wi-Fi。
- 关闭客户端的「自动重连休眠」选项。
- 如果同一时间多台设备使用同一账号，后登录的设备会挤掉先登录的设备。

## 四、网络问题自助排查

1. 使用 ping 内网网关地址，确认基础连通性。
2. 使用 ping internal.company.com 检查 DNS 解析是否正常。
3. 浏览器访问内网首页，确认是否需要重新登录统一身份认证。
4. 关闭个人热点、下载工具或其他占用带宽的软件后重试。
5. 如果只有某个系统无法访问，先询问同部门同事是否正常，以判断是个人问题还是系统故障。

## 五、网络故障报修

如果自助排查无效，请提交「技术问题」工单，并注明：
- 所在楼层与工位号，或当前是否远程办公。
- 有线还是无线网络，连接的网络名称。
- 具体错误提示与发生时间。
- 已尝试的排查步骤。

网络核心设备故障属于紧急事件，请直接联系 IT 值班电话，由值班人员升级处理。
